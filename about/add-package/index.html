The dashboard collects metrics for each package listed in corsa-center/metrics_packages, one YAML file per package. Fill in the form to write that file. The button at the bottom then opens GitHub's new-file page with it filled in: click Propose new file (or Commit changes) and then Create pull request. GitHub forks the repository for you if you can't write to it. You need a GitHub account, and everything in the file is public. Metrics appear after a maintainer merges the pull request and the next daily collection runs.
